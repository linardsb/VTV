# Plan: AI-10.2 — Agent-Side Citation Format Regression Tests

## Context

Citation rendering regresses easily (system prompt tweaks, formatter refactors, LLM behavior drift). AI-10.1 added heading-breadcrumb citations (`citation_anchor`, `url_fragment`, `heading_path`) to knowledge search results. This task pins citation format quality in the AI-7.1 eval suite so regressions are caught by `make eval-check`.

**Approach:** Add 3 new eval cases to `knowledge.yaml` that specifically assert citation format quality. Relax `REQUIRED_CRITERIA_COUNT` from exactly 5 to a 5-6 range so new cases can carry a 6th `citation_format_correct` criterion. Update all dependent tests and the `make_eval_case` factory.

## Security Context Assessment

**No security contexts active.** This task adds read-only test data (YAML eval cases) and relaxes an internal validation constant. No new endpoints, no user input handling, no file uploads, no agent tool changes.

### Step 2: Add 3 new eval cases to `knowledge.yaml`

**File:** `app/core/agents/evals/cases/knowledge.yaml`

Append after case `knowledge_010` (line 195):

```yaml
  # --- AI-10.2: Citation format regression tests ---

  - id: knowledge_011
    prompt: "Kāda ir procedūra autobusu avārijas gadījumā?"
    language: lv
    expected_domain: knowledge
    expected_tools:
      - search_knowledge_base
    quality_criteria:
      - name: factual_accuracy
        description: Procedure steps trace to a real SOP retrieved from the knowledge base.
      - name: citation_quality
        description: Cites SOP using [title](/lv/documents/{id}) format with valid document ID.
      - name: grounding
        description: Every concrete step grounded in retrieved chunks; no improvisation.
      - name: language_correctness
        description: Response in Latvian with correct diacritics.
      - name: honesty
        description: Flags any uncertainty when retrieved chunks are partial.
      - name: citation_format_correct
        description: >-
          Citation uses heading-breadcrumb format: [citation_anchor](/lv/documents/{id}#fragment)
          where citation_anchor contains a heading breadcrumb path (e.g. "doc-title - Section > Subsection").
          The heading_path must be present in the tool return's citation_anchor field. Verify the
          document_id in the citation URL matches the document_id from tool_returns. FAIL if citation
          uses bare filename without breadcrumb when tool_returns show a non-null heading_path.
    notes: "AI-10.2: Citation format regression - asserts breadcrumb heading_path is present in citation."

  - id: knowledge_012
    prompt: "What is the vacation policy for bus drivers?"
    language: en
    expected_domain: knowledge
    expected_tools:
      - search_knowledge_base
    quality_criteria:
      - name: factual_accuracy
        description: Policy details match retrieved HR/policy document.
      - name: citation_quality
        description: Citation links to /en/documents/{id} format.
      - name: grounding
        description: Answer grounded in retrieved document chunks, not training data.
      - name: language_correctness
        description: Response in English; matches user language.
      - name: honesty
        description: Flags uncertainty when retrieved chunks are partial.
      - name: citation_format_correct
        description: >-
          Citation includes a section anchor fragment (#slug) derived from heading_path.
          The url_fragment in tool_returns must appear as the anchor in the citation link.
          Format: [citation_anchor](/en/documents/{id}#url_fragment). FAIL if the anchor
          fragment is missing when tool_returns contain a non-null url_fragment, or if the
          fragment does not match the url_fragment value from the search result.
    notes: "AI-10.2: Citation format regression - asserts section anchor fragment is present."

  - id: knowledge_013
    prompt: "Kādi ir noteikumi par degvielas patēriņa uzskaiti?"
    language: lv
    expected_domain: knowledge
    expected_tools:
      - search_knowledge_base
    quality_criteria:
      - name: factual_accuracy
        description: Fuel accounting rules trace to retrieved operational policy document.
      - name: citation_quality
        description: Citation uses [title](/lv/documents/{id}) format.
      - name: grounding
        description: Answer grounded in retrieved document chunks.
      - name: language_correctness
        description: Response in Latvian with correct diacritics.
      - name: honesty
        description: Flags uncertainty when retrieved chunks are partial.
      - name: citation_format_correct
        description: >-
          Legacy-doc fallback test: when tool_returns show citation_anchor=null and
          heading_path=null (legacy chunk without heading metadata), the citation MUST
          gracefully fall back to [source_filename](/lv/documents/{id}) format WITHOUT
          a heading breadcrumb or anchor fragment. FAIL if the response fabricates a
          breadcrumb that does not exist in tool_returns, or if citation is omitted entirely.
    notes: "AI-10.2: Citation format regression - legacy-doc fallback when heading_path is null."
```
