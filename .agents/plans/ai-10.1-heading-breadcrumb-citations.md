# Plan: AI-10.1 — Render Heading Breadcrumbs in Agent Responses

## Context

AI-4.2 populated `heading_path` on every new chunk (format: `"Section > Subsection > Item"`), and AI-4.3 used it as internal context for parent expansion (`[Section: heading_path]` markers in formatted content). But the user-visible citation still renders as `[Document Title](/lv/documents/42)` with no section anchor. This phase wires the heading breadcrumb through to both the citation formatter and the agent system prompt so dispatchers see exactly which section of a document the answer came from.

## Security Context Assessment

- **CTX-AGENT** — Modifies agent tool output and system prompt. No new credential exposure risk. Citation format is rendered in LLM output displayed to users — sanitization is the frontend's responsibility (existing pattern).
- **CTX-INPUT** — No new user input paths. Query handling unchanged.

No other contexts triggered (no new endpoints, no auth changes, no file handling, no infra changes).

### Step 3: Build citation_anchor in search_knowledge tool formatter

**File:** `app/core/agents/tools/knowledge/search_knowledge.py` (lines 147-158)

Add a helper function to build the citation anchor from heading_path + source filename, and an anchor slug for URL fragment:

```python
import re
import unicodedata

def _heading_to_slug(heading: str) -> str:
    """Convert a heading to a URL-safe anchor slug.

    Handles Latvian diacritics (ā, č, ē, ģ, ī, ķ, ļ, ņ, š, ū, ž) by
    stripping combining marks after NFKD decomposition, then kebab-casing.
    """
    # NFKD decompose then strip combining marks (diacritics)
    nfkd = unicodedata.normalize("NFKD", heading)
    ascii_text = "".join(c for c in nfkd if not unicodedata.combining(c))
    # Lowercase, replace non-alphanumeric with hyphens, collapse runs
    slug = re.sub(r"[^a-z0-9]+", "-", ascii_text.lower()).strip("-")
    return slug


def _build_citation_anchor(source: str, heading_path: str | None) -> str | None:
    """Build pre-formatted citation anchor text from source filename + heading breadcrumb.

    Returns None when heading_path is absent (legacy chunks).
    """
    if not heading_path:
        return None
    # Strip file extension from source for cleaner display
    title = re.sub(r"\.[^.]+$", "", source)
    return f"{title} \u2014 {heading_path}"
```

In the result-building loop (line 147+), compute and pass the anchor:

```python
anchor = _build_citation_anchor(r.document_filename, r.heading_path)
# Compute URL fragment from last heading in path
url_fragment = None
if r.heading_path:
    last_heading = r.heading_path.rsplit(" > ", 1)[-1]
    url_fragment = _heading_to_slug(last_heading)

results.append(

```
